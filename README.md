## About

This is my **first React project** — built to _learn_ React by actually using it, not just to display content. Every part of the page (header, each roadmap card, footer) is its own component.

It's a fully **static site**: no backend, no database, just React + Vite, deployed straight to GitHub Pages.

## ✨ What it is

The site walks through **11 steps** for learning full-stack JavaScript, grouped into phases:

| Phase          | Covers                          |
| -------------- | ------------------------------- |
| 🧱 Foundations | HTML, CSS, JavaScript           |
| 🎨 Frontend    | React, TypeScript               |
| ⚙️ Backend     | Node.js, HTTP & REST, Databases |
| 🔗 Full Stack  | Bringing it together, Next.js   |

Each step is a card with a short explanation of the concept, plus a **"build"** prompt — something small to actually make before moving on to the next step.

## 🛠️ Built with

- **React** — component-based UI
- **Vite** — dev server & build tool

## 🚀 Running it locally

```bash
npm install
npm run dev
```
